# ISMS Foundations Reference — VertexOne Digital Services

## Purpose

The foundational ISO/IEC 27001 ISMS documentation for VertexOne Digital Services is maintained in a separate repository and is intentionally not duplicated within this NIST CSF assessment repository.

This repository builds upon those established ISMS foundations and uses them as the baseline for the NIST Cybersecurity Framework (CSF) 2.0 assessment.

---

## Referenced Repository

**ISMS Foundations Repository — VertexOne Digital Services**

> The ISMS Foundations repository is the authoritative source for foundational ISO/IEC 27001 governance, scope, risk management, controls, and ISMS documentation.

**Repository:** `ISMS-Foundations`

---

## ISMS Foundations Covered

The separate ISMS Foundations repository contains the foundational artifacts required to establish and operate the VertexOne ISMS, including:

- Organizational Context and Business Objectives
- ISMS Scope Statement
- Interested Parties and Requirements
- Information Security Policy
- Risk Management Methodology
- Risk Assessment and Risk Treatment Methodology
- Asset Management Foundations
- Security Governance and Roles
- Control Ownership Structure
- Statement of Applicability (SoA)
- ISMS Documentation Framework
- Management Review Framework
- Internal Audit Framework
- Corrective Action / CAPA Framework

---

## Relationship to This Repository

This repository focuses specifically on the **NIST Cybersecurity Framework (CSF) 2.0 assessment and improvement lifecycle**.

The NIST CSF assessment reuses relevant decisions, evidence, and controls established within the ISMS rather than duplicating the foundational documentation.
