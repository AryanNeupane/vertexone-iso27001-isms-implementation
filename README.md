# VertexOne ISO/IEC 27001 ISMS Implementation

> A complete end-to-end ISO/IEC 27001:2022 Information Security Management System (ISMS) implementation for a fictional enterprise, built as a practical Governance, Risk & Compliance (GRC) portfolio project.

---

## Project Overview

This repository documents the complete implementation of an **Information Security Management System (ISMS)** for **VertexOne Digital Services**, a fictional technology company operating in a hybrid-cloud environment.

The project follows the implementation lifecycle of **ISO/IEC 27001:2022**, beginning with organizational context and governance, progressing through enterprise risk management and Annex A control implementation, and concluding with internal audits, continual improvement, and certification readiness.

Rather than focusing on certification theory, this repository emphasizes **practical implementation**, demonstrating how a Junior GRC Analyst contributes to an enterprise-wide ISMS project.

---

## Business Scenario

**Organization:** VertexOne Digital Services

**Industry:** Technology Services

**Employees:** ~1,000

**Environment**

- Hybrid workforce
- Microsoft 365
- Azure Cloud
- Customer information
- Third-party vendors
- Enterprise applications
- Multi-department operations

VertexOne has decided to implement ISO/IEC 27001:2022 to strengthen its information security governance, improve risk management, and prepare for certification.
