# ISO/IEC 27001:2022 – ISMS Foundation

This repository contains the foundational governance documentation developed for the fictional organization **VertexOne Digital Services** as part of an **ISO/IEC 27001:2022 Information Security Management System (ISMS)** implementation.

The objective is to demonstrate how an organization establishes the governance, scope, responsibilities, and security objectives required before implementing security controls.

## Documents Included

- Organizational Context
- Interested Parties Register
- ISMS Scope Statement
- Information Security Policy
- ISMS Roles & Responsibilities Register
- RACI Matrix
- Security Objectives Register

## ISO/IEC 27001 Clauses Covered

- **Clause 4** – Context of the Organization
- **Clause 5** – Leadership
- **Clause 6.2** – Information Security Objectives

## Purpose

This repository is part of my GRC learning portfolio and demonstrates practical experience in creating ISO/IEC 27001 governance documentation using a realistic business scenario.
